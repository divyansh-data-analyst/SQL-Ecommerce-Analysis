# SQL E-commerce Sales Analysis

## Project Overview
This project focuses on analyzing an e-commerce sales dataset using SQL (MySQL) to answer key business questions and derive actionable insights.  
The analysis covers overall sales performance, category performance, payment method usage, discount impact, time-based trends, and customer purchase behavior.


## Dataset
- **Source:** Kaggle (E-commerce Sales Dataset)
- **Format:** CSV
- **Description:** The dataset contains transaction-level e-commerce sales data.
- **Key Columns:**
  - User_ID
  - Product_ID
  - Category
  - Price (Rs.)
  - Discount (%)
  - Final_Price (Rs.)
  - Payment_Method
  - Purchase_Date
